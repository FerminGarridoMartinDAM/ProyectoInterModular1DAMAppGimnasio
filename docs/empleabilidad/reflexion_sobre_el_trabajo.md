# Reflexión sobre el Proyecto Intermodular

## Aprendizajes del proceso
Desarrollar la App de Gestión de Gimnasio ha sido un reto. Me ha permitido ver cómo se conectan los módulos de Programación y Bases de Datos en un entorno real mediante la conexión JDBC con Supabase. Ha sido una gran experiencia ver la integration de las diferentes asignaturas en un solo proyecto

## Puntos clave
- Integración Técnica: La experiencia de gestionar datos reales en la nube ha sido un aprendizaje muy valioso de este primer año.
- Gestión y Planificación: Trabajar con una fecha límite me ha enseñado a priorizar las funciones críticas del sistema para asegurar una entrega funcional y profesional.
- Resolución de Problemas: He mejorado mi capacidad para depurar errores lógicos y adaptar el código ante imprevistos técnicos.

## Visión de futuro
Mi plan es seguir formándome con la misma intensidad, aprovechando cada proyecto para dominar nuevas herramientas y acercarme cada vez más al perfil de experto en el sector.
