# Portfolio: GimnasioApp

## Presentación del Proyecto
GimnasioApp es una aplicación de gestión integral desarrollada para digitalizar la operativa de gimnasios y centros deportivos. El proyecto sustituye métodos obsoletos por un sistema centralizado que garantiza la integridad de los datos.

- Qué es el proyecto: Una herramienta de escritorio para el control total sobre los activos del gimnasio.
- Problema que resuelve: Centraliza la gestión de socios, planes y reservas, evitando errores de duplicidad.
- Público objetivo: Administradores de gimnasios pequeños y medianos que buscan profesionalizar su gestión.

## Ficha Técnica y Tecnologías
- Backend: Java con principios de Programación Orientada a Objetos.
- Base de Datos: PostgreSQL alojada en Supabase (Cloud).
- Conectividad: Implementación de JDBC para comunicación fluida lógica-datos.
- Intercambio de datos: Uso de XML y validación mediante esquemas XSD para exportación de catálogos.

## Funcionalidades Destacadas
- Gestión de Usuarios (altas, bajas y modificaciones de socios y entrenadores).
- Administración dinámica de planes de precios.
- Sistema automatizado de reservas en sesiones específicas.
