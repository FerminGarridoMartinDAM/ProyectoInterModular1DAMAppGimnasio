# Proyecto Intermodular 1 DAM - App Gimnasio

## Objetivo del proyecto
El objetivo principal de este proyecto es optimizar y facilitar la gestión diaria de un gimnasio pequeño o mediano, sustituyendo el uso de papel o Excel por un sistema centralizado.

## Idea de la aplicación
He desarrollado una aplicación de consola en Java que cuenta con las siguientes funcionalidades principales:
- Gestionar a los socios y a los entrenadores (altas, modificaciones, eliminaciones).
- Crear y administrar los planes de precios o tarifas.
- Organizar el calendario de las clases y actividades.
- Permitir que los socios reserven plaza en las sesiones.

## Programas utilizados
Para construir este proyecto he utilizado:
- Java como lenguaje de programación.
- PostgreSQL para la base de datos (alojada en la nube con Supabase).
- IntelliJ IDEA y Visual Studio Code como editores de código.

## Cómo probar la aplicación
1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto con un IDE que soporte Java.
3. La aplicación se conecta a una base de datos en la nube. Las credenciales de acceso para la corrección se facilitarán en la clase ConexionDB.java.
4. Ejecutar el archivo Main.java para iniciar el menú.

## Organización de las carpetas
Para facilitar la corrección del proyecto intermodular, el repositorio está dividido así:

- /src: Código fuente de la aplicación (Programación y Ampliación de Programación).
- /sql: Scripts de creación y diagramas de la base de datos (Bases de Datos).
- /xml: Archivos de datos estructurados (Lenguajes de Marcas).
- /docs/sistemas: Informe técnico del entorno (Sistemas Informáticos).
- /docs/empleabilidad: Perfil profesional y portfolio (IPE).
